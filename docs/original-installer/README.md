# The original game's installer: not the download you want

**To play the enhanced edition, do not use this folder.** Go to the
[install guide](../install.md) ([Português](../install.pt.md)): it has the download for your device.

`penumbra_setup.exe` here is the installer of the **original 2010 game** (Portuguese, Windows only),
*Penumbra and the Castle of Shadows* by André Santee / Asantee. It is kept only as the source of the
`extracted/` folder, which the enhanced edition reads its art, music and scripts from. It is the
original authors' property and no licence to it is granted by this repository
([LICENSE.md](../../LICENSE.md)). It is not the enhanced edition, and it does not contain it.
